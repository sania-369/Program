# 🧠 Программа ЕТВП: Строгая научная реализация

Этот репозиторий содержит **формальную математическую модель** и **исполняемый код** для нейросетевого слоя, построенного на принципах Единой теории вихревого поля (ЕТВП). Версия 2.5 представляет собой **финальную универсальную архитектуру**, объединяющую когерентную динамику, комплексную активацию и стохастическую самокоррекцию.

---

## 📐 Математическая основа

В основе слоя лежит **стохастическое дифференциальное уравнение** (SDE), моделирующее эволюцию когерентного поля:

\[
z(t+\Delta t) = z(t) + \Delta t \cdot \left[ f(z) - \mu \nabla^2 f(z) \right] + \sqrt{\Delta t} \cdot \eta \cdot \xi(t) \cdot \tanh(\beta |f(z)|)
\]

### Ключевые компоненты:
*   **Cardioid-активация:** Аналитическая комплексная функция \( f(z) = \frac{1}{2}(1 + \cos(\angle z)) \cdot z \), удовлетворяющая условиям Коши-Римана и сохраняющая когерентность фазы.
*   **Лапласиан (диффузионный оператор):** Обеспечивает пространственную или признаковую регуляризацию, не связывая объекты в батче.
*   **Z-принцип:** Построчная проекция комплексных весов на сферу радиуса \( R_{max} \) для стабилизации обучения без затухания градиентов.
*   **Обучаемая вязкость вакуума:** Параметр \( \mu = \text{softplus}(\theta_\mu) \), управляющий интенсивностью диффузии.
*   **Стохастическая самокоррекция:** Шум с корректным физическим масштабом \( \sqrt{\Delta t} \), модулированный когерентностью поля.

## 🧩 Архитектура слоя

Ключевой файл: **`Универсальный комплексный слой ЕТВП.py`**

Слой `ETVP_ComplexLayer` поддерживает:
*   **2D входы:** `[batch, features]` — лапласиан по признакам.
*   **4D входы:** `[batch, channels, height, width]` — пространственный лапласиан.
*   **Автоопределение режима** или принудительное задание через параметр `laplace_mode`.
*   **Полноценное комплексное линейное преобразование** с весами \( W = W_{re} + iW_{im} \).
*   **Интеграцию по методу Эйлера-Маруямы** для SDE.

## 🚀 Быстрый старт

1.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
    (Основные требования: `torch`, `numpy`, `matplotlib`)

2.  **Протестируйте слой:**
    ```bash
    python Универсальный\ комплексный\ слой\ ЕТВП.py
    ```
    Будут запущены все проверки (2D/4D входы, Z-принцип, масштаб шума), подтверждающие корректность реализации.

3.  **Интегрируйте слой в свою архитектуру:**
    ```python
    from Универсальный комплексный слой ЕТВП import ETVP_ComplexLayer

    layer = ETVP_ComplexLayer(dim_in=128, dim_out=256, R_max=1.0, eta_init=0.01)

    # Для комплексных данных
    out_re, out_im = layer(x_re, x_im, dt=0.1)
    ```

## 🔬 Связь с физическими экспериментами

Архитектура слоя является вычислительным воплощением предсказаний ЕТВП, которые могут быть проверены в реальных экспериментах:

*   **FCC:** Предсказание \( \alpha_s(100 \, \text{ТэВ}) \approx 0.09 \).
*   **ATOMKI:** Энергетический «бег» угла разлёта при распаде X17.
*   **DUNE/Hyper-K:** Предсказание \( \delta_{CP} = -155^\circ \) и нормальной иерархии масс нейтрино.
