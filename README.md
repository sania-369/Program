# ETVP Toolkit

Набор инструментов на базе геометрии E₈.

## Установка:
pip install -r requirements.txt

## Запуск:
python main.py

## Модули:
- etvp_core.py — ядро
- etvp_crypto.py — криптография
- etvp_folding.py — фолдинг белков
- etvp_materials.py — материалы
- etvp_quantum.py — квантовый симулятор
- etvp_predictions.py — предсказания
