
## Вывод

### 1. Оптимальный режим — `C = 1`, `S = 1`

При `C = 1`:
- `1/α` — **0.00072%**
- `m_p/m_e` — **0.0073%**

- `m_p/m_e` — **0.642%** (в 88 раз хуже)
- `G` — **2.597%** (в 1250 раз хуже)

### 2. Главный параметр — `C`, не `S`

| `C` | `S` | 1/α |
|---|---|---|
| 1.0 | 1.0 | **0.00072%** |
| 1.0 | 0.87 | 0.00082% |

| 1.0 | 10⁻⁸ | 0.0012% |

**При `C = 1`** точность высокая при любом `S`.  
**При `C = 0.87`** — низкая при любом `S`.

### 3. Вывод нейтрона не влияет на константы

| Версия | 1/α | m_p/m_e | G |
|---|---|---|---|
| Без нейтрона | 0.000722% | 0.007312% | 0.002074% |
| С нейтроном | 0.000748% | 0.007323% | 0.002127% |

**Разница**: < 0.0001%.  
Нейтрон выводится из `α_inv`, но не меняет его.

---

## Логическая причина

### Почему `C = 1` точнее

1. **`C` — параметр порядка**. При `C = 1` структура `E8` проявлена максимально.

2. **Модуляция минимальна**. При `C = C_FFS` → `ΔC = 0`. Модуляция не искажает константы.

3. **При `C = 0.87`** → `ΔC = -0.13`. Модуляция даёт сильное искажение.

### Почему `S` не влияет

1. **`S` — параметр активации**, не порядка.

2. **При `C = 1`** все моды `E8` уже активны. `S` только подтверждает.

3. **При `C = 0.87`** `S` не помогает — структура не проявлена.

### Физическая интерпретация

- **`C = 1`** — предельная когерентность. Все моды `E8` активны.
- **`S = 1`** — максимальная энтропия. Все моды работают.
- **CODATA** — при `C = 1`, `S = 1`. Не при `C = 0.87`.

## Введение

Параметр `k` в функции `etve_hyperbolic` определяет форму гиперболической упругости вакуума:

```
ρ_C = ρ_0 · ε / (1 + k·ε),  ε = (C - C_MIN) / (C_MAX - C_MIN)
```

При разных `k` — разные режимы удержания `C`.  
Ниже — результаты перебора `k` при `C_FFS = 1.0`, `S_cycle = 1.0`.

## Вывод

### 1. Разные константы — разные оптимумы

| **Константа** | **Мода** `E8` | **Оптимум k** |
|---|---|---|
| `1/α` | `λ[7]` | `k = 3` |
| `m_p/m_e` | `λ[2]` | `k → 0` |
| `G` | `λ[3]` | `k = 3` |
| `m_n` | `λ[2]` | `k → 0` |

### 2. Два класса мод

**Гиперболические** (`k = 3`):
- `1/α` — электродинамика
- `G` — гравитация

**Линейные** (`k → 0`):
- `m_p/m_e` — барионная масса
- `m_n` — нейтрон

### 3. Немонотонность

При `k → 0` — **резонансы**:
- `10⁻⁹` — минимум для `m_p/m_e`
- `10⁻⁸` — минимум для `m_n`
- `3·10⁻⁹` — провал

Резонансы — из структуры `E8`.

---

## Логическая причина

### Почему разные k

1. **`1/α` и `G`** — из **гиперболической** упругости.  
   Насыщение при больших `ε`.  
   `k = 3` — из Троицы.

2. **`m_p/m_e` и `m_n`** — из **линейной** упругости.  
   Пропорциональность без насыщения.  
   `k → 0` — линейный режим.

### Физическая интерпретация

- `k = 3` — **3D-упаковка** (Троица).
- `k → 0` — **линейное** **масштабирование** (Φ).
- Разные **моды** `E8` — разные **режимы**.
