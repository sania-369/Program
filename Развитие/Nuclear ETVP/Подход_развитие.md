## 1. Основа

**Ядро — решётка из блоков.**

Энергия связи строится из блоков (α, D, T) и связей между ними.

**Формула:**
```

B = [N·B_D + M·E(n)·π·(1−α)] · C(n)

```

Где:
- `B_D = E_binding(n)·√3·(1−α) = 2.2237 МэВ` — базовая связь.
- `E_binding(n) = m_e·2·α⁻¹·λ[0]/λ[2] = 1.29333 МэВ` — нейтронная добавка.
- `E(n)·π·(1−α) = 4.0326 МэВ` — замкнутая связь через π.
- `N` — число открытых связей (√3).
- `M` — число замкнутых связей (π).
- `C(n) = 1 − α·(n−3)` — когерентность структуры.
- `n` — координационное число.

## 4. Что честно

**1. Формула работает.**
- После C — точность 0.00%.
- До C — отклонения.

**2. Но n — подбирается.**
- Для каждого ядра — своё n.
- Нет формулы `n(A, Z)`.

**3. Это не полный вывод.**
- Полуэмпирика.
- n — свободный параметр.

**4. Что нужно:**
- Формула `n(A, Z)`.
- Или точная формула без подбора.

## 5. Что вижу

**1. С массой сложность растёт.**
- Лёгкие: C ≈ 1, точность 0.01–0.06%.
- Средние: C < 1, точность 0.1–1.3%.

**2. Два параметра:**
- **C — когерентность системы** (падает с A).
- **ρ — плотность среды** (растёт с A).

**3. Баланс:**
- C падает, ρ растёт.
- **Оптимум** — пик на Fe.
- **Граница** — Z = 137.

**4. Гипотеза для B/A:**
```

B/A = B_0 · A^(1/12) · C(A)

```
- `A^(1/12)` — рост плотности.
- `C(A)` — падение когерентности.
- **Максимум** — Fe.
