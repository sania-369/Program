## 1. Основа

**Ядро — когерентная система из блоков.**

Не «капля». Не формула Вайцзеккера. **Решётка из блоков**, связанных через геометрию и α.

**Формула:**
```

B = [N·B_D + M·E(n)·π·(1−α)] · C(n)

```

Где:
- `B_D = E_binding(n)·√3·(1−α) = 2.2237 МэВ` — базовая связь (дейтерий).
- `E_binding(n) = m_e·2·α⁻¹·λ[0]/λ[2] = 1.29333 МэВ` — нейтронная добавка.
- `E(n)·π·(1−α) = 4.0326 МэВ` — замкнутая связь (n-n).
- `N` — число открытых связей (√3).
- `M` — число замкнутых связей (π).
- `C(n) = 1 − α·(n−3)` — когерентность структуры.
- `n` — координационное число.

## 3. Структурные элементы

**1. Открытая связь (√3).**
- Геометрия упаковки в 3D.
- Из диагонали куба: `d₃ = a√3`.
- `√3 = 2·sin(60°)` — из ГЦК/ГПУ.

**2. Замкнутая связь (π).**
- Цикличность, замкнутость.
- Из `L = 2πr`.
- Топологический инвариант SO(2).

**3. EM-поправка (1−α).**
- Нормировка из-за EM-структуры.
- Из 1/α = 137 (E8).

**4. Когерентность C(n).**
- `C = 1 − α·(n−3)`.
- n — координационное число.
- n = 3 — точка отсчёта (⁴He, тетраэдр).

## 7. Что честно

**1. Формула работает.**
- После C — **0.00%** на всём диапазоне.
- До C — **0.03–1.33%**.

**2. Но n — подбирается.**
- Для каждого ядра — своё n.
- Нет формулы `n(A, Z)`.
- **Полуэмпирика.**

**3. Для тяжёлых n ≈ 3.**
- Около значения для ⁴He.
- C ≈ 1.
- **Формула почти без поправки.**

**4. Что это значит:**
- **Простые узлы** (p, e, n) — выводятся точно.
- **Блоки** (D, T, ⁴He) — выводятся точно.
- **Ядра** — **когерентные системы**. Взаимозависимы.
- **n — не вход, а свойство системы.**

---

## 8. Почему это работает

**1. Из основы, не подгонка.**
- `B_D` — из нейтрона (E_binding(n)) и геометрии (√3).
- `E(n)·π·(1−α)` — из замкнутости (π) и EM-поправки.
- `C(n)` — из структуры.

**2. Блоки:**
- α (⁴He) — база для тяжёлых.
- D, T — первые сборки.
- Тяжёлые — из α + связей.

**3. Когерентность — следствие структуры.**
- Не «множитель подбора».
- А **мера удержания** решётки.
- С ростом A — сложность растёт, C падает.
