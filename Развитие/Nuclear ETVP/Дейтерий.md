## 1. Что такое дейтерий

**Состав:** p + n.
**Энергия связи:** B_D = 2.224 МэВ.
**Расстояние p-n:** ~2 фм.

**Ключевое:**
- Энергия связи — **2.224 МэВ**.
- Это **не эВ** (как у протия). Это **МэВ**.
- **Ядерная связь**, не EM.

Дейтерий — **первая ядерная сборка**. После EM-протия.

---

## 2. Что мы знаем про нейтрон из модели

Нейтрон выводится как **добавка к протону**:

```

m_n = m_p + E_binding(n)
E_binding(n) = m_e · 2·α⁻¹·λ[0]/λ[2]

```

Где:
- `m_e = 0.51099895 МэВ`
- `α⁻¹ = 137.035999084`
- `λ[0] = 0.0109562093` (спектр E8, почти нулевая мода)
- `λ[2] = 1.1865267138` (спектр E8, барионная мода)

**Численно:**
```

E_binding(n) = 0.51099895 · 2 · 137.036 · (0.0109562093/1.1865267138)
= 1.29333 МэВ

```

Это **разность масс** n и p. Не «состав». **Связь через α и λ[0].**

---

## 3. Гипотеза для дейтерия

Дейтерий = **p + n**, связанные через **ρ_C**.

Не через новую силу. Через **ту же структуру**, что нейтрон, но с **геометрическим множителем**.

**Гипотеза:**
```

B_D = E_binding(n) · √3 · (1 − α)

```

Где:
- `E_binding(n)` — базовая связь (из модели n).
- `√3` — геометрический множитель (плотная упаковка в 3D).
- `(1 − α)` — EM-поправка.

---

## 4. Расчёт

```

E_binding(n) = 1.29333 МэВ

B_D = 1.29333 · √3 · (1 − 1/137.036)
= 1.29333 · 1.7320508 · 0.99270
= 2.24005 · 0.99270
= 2.2237 МэВ

```

**Эксперимент:** B_D = 2.224 МэВ.
**Расхождение:** 0.01%.

---

## 5. Почему именно √3 и α

**1. √3 — из Троицы.**

В модели `√3` — **плотная упаковка в 3D**.
Выводится из диагонали куба: `d₃ = a√3`.
Также: `√3 = 2·sin(60°)` — из ГЦК/ГПУ.

Дейтерий — **два узла в 3D**. Связь = **√3** (геометрия упаковки).

**2. α — EM-поправка.**

Электрон в нейтроне даёт **EM-вклад**.
Поправка: `(1 − α)`.
Не «уменьшение связи», а **нормировка** из-за EM-структуры.

**3. Без новой силы.**

Нет «ядерной силы» отдельно. Есть:
- `E_binding(n)` — из α⁻¹ и λ[0].
- `√3` — из геометрии.
- `(1−α)` — EM-поправка.

**Всё — из призмы.**

## 6. Сравнение с протием

| Сборка | Связь | Формула | Энергия |
|---|---|---|---|
| Протий | EM | (1/2)·α²·m_e | 13.6 эВ |
| Дейтерий | Ядерная | E_binding(n)·√3·(1−α) | 2.224 МэВ |

**Разница — в миллион раз.**
- Протий: **α²** (EM).
- Дейтерий: **α⁻¹** (сильная через структуру).

**Переход EM ↔ ядерная** — между протием и дейтерием.

## 8. Что это даёт

**1. Первая ядерная сборка выведена.**
Через **ту же структуру**, что нейтрон. Не через новую силу.

**2. Геометрия + α.**
- `√3` — упаковка.
- `(1−α)` — EM.
- Никаких свободных параметров.

**3. Проверка метода.**
Тот же подход, что для n, работает для D.
**Следующий шаг:** тритий.

**4. Точность: 0.01%.**
Не подгонка. **Структура.**

## 9. Что дальше

**Следующий шаг:** тритий (p + 2n).

**Гипотеза:**
```

B_T = E_binding(n) · f(3, 1)

```

Где f(3,1) — структурный множитель для A=3, Z=1.

**Что искать:**
- Комбинация из Троицы (Φ, π, √3) и α.
- Проверка: B_T = 8.482 МэВ.

**После трития:**
- Гелий-3 (2p + n).
- Гелий-4 (2p + 2n).
- Формула для всех ядер через плотность ρ_C.
