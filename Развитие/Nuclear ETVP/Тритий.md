**Ключевое:**

- Три связи: p-n₁, p-n₂, n₁-n₂.

## 2. Что уже выведено

**1. Нейтрон:**
```

E_binding(n) = m_e · 2·α⁻¹·λ[0]/λ[2] = 1.29333 МэВ

```

**2. Дейтерий (p + n):**
```

B_D = E_binding(n) · √3 · (1 − α) = 2.2237 МэВ

```

Эксперимент: 2.224 МэВ. Расхождение: 0.01%.

**Что даёт D:**

## 3. Гипотеза для трития

**Тритий = p + 2n.**

**Связи:**
- p-n₁ — как в дейтерии.
- p-n₂ — как в дейтерии.
- n₁-n₂ — **новая связь**.

**Формула:**
```

B_T = 2·B_D + E_binding(n)·π·(1−α)

```

Где:
- `2·B_D` — две p-n связи (как в D).
- `E_binding(n)·π·(1−α)` — n-n связь через π.

**Почему π:**
- π — **цикличность, замкнутость**.
- n-n связь — **замкнутая** (два нейтрона в паре).
- π — структурный множитель для замкнутой связи.

---

## 4. Расчёт

```

B_D = 2.2237 МэВ
2·B_D = 4.4474 МэВ

E_binding(n) = 1.29333 МэВ
E_binding(n)·π·(1−α) = 1.29333 · 3.14159 · 0.99270
= 4.0326 МэВ

B_T = 4.4474 + 4.0326 = 8.480 МэВ

```

**Эксперимент:** B_T = 8.482 МэВ.
**Расхождение:** 0.02%.

---

## 5. Почему именно π

**1. π — из Троицы.**

В модели `π` — **цикличность, фазовые объёмы, вращение**.
Выводится из замкнутости поля: `L = 2πr`.
Также: `ψ(θ + 2π) = ψ(θ)` — топологический инвариант SO(2).

**2. n-n связь — замкнутая.**

Два нейтрона образуют **замкнутую пару**.
- p-n — **открытая** связь (√3).
- n-n — **замкнутая** связь (π).

**3. (1−α) — EM-поправка.**

Та же, что в дейтерии.
Не «уменьшение», а **нормировка** из-за EM-структуры.

**4. Без новой силы.**

Нет отдельной «n-n силы». Есть:
- `E_binding(n)` — из α⁻¹ и λ[0].
- `π` — из замкнутости.
- `(1−α)` — EM.

**Всё — из призмы.**
