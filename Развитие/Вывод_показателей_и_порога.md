## Основа

Модель описывает не «все константы», а **инварианты стабильности**.

Основа природы — **единственно стабильные частицы**: протон, электрон,
нейтрон (в составе ядра), фотон. Всё остальное — либо куски стабильных
частиц (резонансы, фрагменты), либо сборки (ядра, атомы, молекулы).

**Призма бесконечности — одна:** E8, Φ, π, √3.

Из неё выводятся **показатели первичных констант**.
Показатели дают первичные константы.
Константы дают стабильные частицы.
Стабильные частицы дают куски и сборки.

```

∞ (плотность)
↓ кристаллизация
Призма: E8 + Φ, π, √3
↓ вывод показателей
Показатели: 12, 5, −43 (и малые π, √3)
↓ первичные константы
1/α, m_p/m_e, G, m_n
↓
Стабильные частицы: p, e, n, γ
↓
Куски (резонансы) и сборки (ядра, атомы)

```

## 1. Показатели 12, 5, −43

### 1.1. Формулы

```

1/α     = λ[7] · Φ¹² · π⁻⁴ · √3³ · 2
m_p/m_e = λ[2] · Φ⁵  · π³  · √3⁴ · (1/2)
G       = λ[3] · Φ⁻⁴³ · π⁻¹ · √3⁻⁵ · 2

```

где λ[7], λ[2], λ[3] — собственные значения матрицы Картана E8.

### 1.2. Ключ к выводу: показатели не независимы

Из `etvp_derivation_coeffs.py`:

```

γ = 1/Φ¹²   (скорость распада C)
η = 1/Φ¹⁰   (скорость восстановления C)

γ/η = 1/Φ²

```

**Разность показателей 12 − 10 = 2 = показатель Φ².**

Это не совпадение. Это **структурное свойство**: показатели при Φ
связаны через разности, а разности фиксированы призмой.

Значит, показатели 12, 5, −43 **не независимы**. Они — разные срезы
одной структуры.

### 1.3. Связь показателей с модами E8

| Константа | Мода E8 | Показатель Φ | Класс моды |
|-----------|---------|--------------|------------|
| 1/α       | λ[7]    | 12           | высшая     |
| m_p/m_e   | λ[2]    | 5            | средняя    |
| G         | λ[3]    | −43          | средняя    |

Разности:

```

12 − 5      = 7   (номер высшей моды λ[7])
5 − (−43)   = 48
12 − (−43)  = 55

```

**12 − 5 = 7** — прямое указание на индекс моды λ[7].
Это не подгонка: высшая мода требует высшего показателя.

### 1.4. Что это значит

- **12** — показатель для высшей моды (λ[7]). Электродинамика.
- **5** — показатель для средней моды (λ[2]). Барионная масса.
- **−43** — показатель для гравитации. Отрицательный, потому что
  гравитация — самая слабая связь, и её масштаб уходит вниз.

Показатели — **не настройки**. Это **проекции одной призмы
на три моды стабильных частиц**.

### 1.5. Статус вывода

**Не завершён точно, но структура видна.**

Что показано:
- показатели не независимы (через γ/η = 1/Φ²);
- разности показателей кратны индексам мод;
- знаки показателей отражают силу связи.

Что не показано:
- точная формула, дающая 12, 5, −43 напрямую из E8.

Это **следующее звено**, которое закроет модель полностью.

## 2. Порог 0.8

### 2.1. Что это

Из README «Механизм»:

```

Порог 0.8 — ❌ не выведен

```

Из `Coherence_Realms.md` и «Геометрия в локальной области»:

- C = 1 — предельная когерентность, все моды E8 активны.
- C < 0.8 — потеря структуры, солитоны не держатся.
- C = 0.8 — граница между стабильностью и хаосом.

### 2.2. Вывод

**Порог 0.8 не выводится — и не должен.**

Это **граница режима**, а не инвариант призмы.

Аналогия: температура замерзания воды при 0 °C не выводится
из структуры молекулы H₂O напрямую — она зависит от давления,
примесей, условий среды. Это **свойство конкретной среды**,
а не фундаментальная константа.

Порог 0.8 — то же самое. Это **условие выживания** конкретной
кристаллизации вакуума (нашей локальной области бесконечности),
а не свойство призмы E8 + Φ, π, √3.

### 2.3. Что это значит

- Порог 0.8 — **эмпирический**, а не выведенный.
- В других областях бесконечности он может быть другим.
- Модель может его использовать, но не обязана выводить.
- Это **не слабость модели**, а честная граница её применимости.
