# ETVP: Нелинейное взаимодействие мод

## 1. Проблема

Линейная зависимость λ_i от C не даёт нескольких минимумов.
Нужно нелинейное взаимодействие.

## 2. Что известно

В коде: M[i,i] += abs(projection)·(C_MAX − C)/(C_MAX − C_MIN)
Это нелинейная добавка к диагонали.

## 3. Гипотеза

V(Ψ) = Σ_i λ_i|A_i|² + Σ_{i,j} g_{ij}|A_i|²|A_j|²

g_{ij} — коэффициенты взаимодействия, зависят от C.

C > 0.8: g_{ij} малы. Один минимум.
C < 0.8: g_{ij} растут. Несколько минимумов.

## 4. Скептическая проверка

1. Что такое g_{ij}? Как вывести из E8? Не выведено.
2. Почему g_{ij} растут при C < 0.8? Не доказано.
3. Связь с Û — гипотеза.
