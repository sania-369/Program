# ETVP: Расширенный поиск формулы фиксации — результаты

## 1. Результаты

| Формула | Корреляция |
|---|---|
| Степенная | 0.397 |
| Логарифмическая | 0.120 |
| Экспоненциальная | 0.106 |
| Через Φ | 0.107 |
| Через триаду | 0.090 |
| Φ-степенная | 0.115 |

Лучшая: степенная, α = 0.78, β = 0.78, γ = 4.46, корреляция 0.397.

## 2. Что это значит

1. Степенная — лучшая, но слабая.
   0.397 — умеренная корреляция. Не сильная.

2. Показатели близки к 1.
   α = 0.78, β = 0.78. Близко к линейности.

3. γ = 4.46 — сильная зависимость от S.
   Шум подавляет фиксацию очень сильно.

4. Формулы через Φ, π, √3 — хуже.
   Корреляции < 0.12. Практически нет связи.

## 3. Честный вывод

1. Уравнение удержания не работает в предложенных формах.
   Ни одна формула не даёт корреляцию > 0.8.

2. Проблема — в определении фиксации.
   Фиксация = удержание / шум — гипотеза. Не выведено.

3. Возможно, фиксация — не функция от C_оп, n, S.
   Возможно, фиксация — свойство самой структуры Ŵ.

4. Численная проверка не подтверждает гипотезу.
   Корреляция 0.397 недостаточна.

## 4. Что дальше

- Переопределить фиксацию.
- Проверить другие гипотезы.
- Возможно, фиксация — не скаляр, а структура.
