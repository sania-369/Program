# ETVP: Фиксация как переход через седло

## 1. Гипотеза

Фиксация — не «выбор моды».
Переход через седловую точку в пространстве состояний.

## 2. Формализм

dΨ/dt = −∂V/∂Ψ + шум

V — потенциал, зависящий от C.

При C > 0.8: V имеет один минимум (суперпозиция).
При C < 0.8: V имеет несколько минимумов (фиксация).

## 3. Механизм

Спонтанное нарушение симметрии при изменении ландшафта V.

## 4. Скептическая проверка

1. Что такое V? Как зависит от C? Не выведено.
2. Почему при C < 0.8 несколько минимумов? Не доказано.
3. Связь с Û — гипотеза.
