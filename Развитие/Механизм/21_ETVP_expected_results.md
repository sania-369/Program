# ETVP: Ожидаемые результаты численной проверки

## 1. Если механизм верен

C = 1: один минимум V.
C < 0.8: несколько минимумов V.

## 2. Если нет

При всех C: один минимум. Механизм опровергнут.
При всех C: много минимумов. Механизм не работает.

## 3. Что это даёт

Численная проверка — решающий тест.
Если подтвердится — механизм найден.
Если нет — гипотеза опровергнута.
