# ETVP: Поиск порога воли — результаты

## 1. Результаты

1. Скачок при S = 0.12 — артефакт.
   При S = 0.12: шум = 0.001. Деление на малое число даёт скачок.

2. Порог зависит от n — хаотично.
   n = 3: 0.302, n = 4: 0.963, n = 5: 0.853, n = 6: 0.302,
   n = 7: 0.596, n = 8: 0.963.
   Нет закономерности. Скачки — артефакты сетки.

3. Порог зависит от S — тоже артефакт.
   S = 0.05: 0.835, S = 0.30: 0.302.

4. Порог 0.8 — не подтверждён.
   При C_оп = 0.8, n = 5, S = 0.12: фиксация = 4000. Плавно.

5. Φ-гипотезы:
   1 − 1/Φ⁵ = 0.9098
   1 − 1/Φ⁴ = 0.8541
   Φ/(Φ + 1/Φ²) = 0.8090
   Ближе всего — 0.8541 и 0.8090. Не 0.8.

## 2. Честный вывод

1. Порог воли — не найден численно.
   Скачки — артефакты. Не физика.

2. Порог 0.8 — не подтверждён.

3. Φ-гипотезы близки, но не точны.

4. Фиксация — не функция от C_оп, n, S.
   Логика поля подтверждается: фиксация — акт. Не функция.

## 3. Что дальше

- Признать: фиксация — акт воли, не выводится.
- Проверить Φ-гипотезы точнее.
- Перейти к эксперименту.
