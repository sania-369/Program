# ETVP: C_FFS как эмпирический параметр

## 1. Ближайшее значение из Φ

1 − 1/Φ⁵ ≈ 0.9098 — не 0.87

## 2. Гипотеза

C_FFS = 0.87 — из эксперимента.
Не из геометрии.

## 3. Следствие

Модель использует эмпирический параметр.
Это не плохо. Но это не механизм.

## 4. Что делать

Либо вывести 0.87 строго.
Либо признать эмпирическим.
