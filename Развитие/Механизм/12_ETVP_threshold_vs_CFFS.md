# ETVP: Порог 0.8 и C_FFS = 0.87

## 1. Что известно

Порог = 0.8 (из модели).
C_FFS = 0.87 (из данных FFS).

## 2. Гипотеза

Порог ≈ C_FFS. Разница 0.07 — в пределах погрешности.

## 3. Следствие

Фиксация происходит при достижении C_FFS.
Пока C < C_FFS — система не устойчива.
При C ≈ C_FFS — устойчива.

## 4. Открытый вопрос

Почему 0.87?
Если порог = C_FFS, то вопрос сводится к выводу C_FFS.
