C_FFS = 0.87 — целевое значение C в модели.
Из данных FFS (arXiv:2602.17657).

## 2. Попытки вывода

1. (λ[7]−λ[2])/λ[7] ≈ 0.7027 — не 0.87
2. (λ[7]−λ[0])/λ[7] ≈ 0.9972 — не 0.87
3. Φ²/(Φ²+1) ≈ 0.7236 — не 0.87
4. 1 − 1/Φ⁵ ≈ 0.9098 — близко, не 0.87
5. 1 − 1/Φ⁵·⁵ ≈ 0.9485 — не 0.87

C_FFS = 0.87 — эмпирика.
Из данных FFS.
Не из первых принципов.
