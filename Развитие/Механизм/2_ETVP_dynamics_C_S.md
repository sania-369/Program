# ETVP: Динамика C и S — уравнение эволюции

## 1. Уравнения

C(t+dt) = C(t)·(1−γ) + γ·C_FFS + шум
S(t+dt) = S(t)·(1−η) + η·S_cycle + шум

где γ = 1/Φ¹², η = 1/Φ¹⁰

## 2. Физический смысл

- C стремится к C_FFS со скоростью γ (декогеренция)
- S стремится к S_cycle со скоростью η (релаксация)
- Шум — внешний фактор

## 3. Скептическая проверка

1. Почему γ = 1/Φ¹²? Не доказано.
2. Почему η = 1/Φ¹⁰? Не доказано.
3. Почему шум ·0.1 и ·0.01? Не выведено.
4. Почему C_FFS = 0.87? Эмпирика.

## 4. Открытые вопросы

- Вывести γ, η из Φ строго.
- Вывести шум из геометрии.
- Вывести C_FFS из E8.
