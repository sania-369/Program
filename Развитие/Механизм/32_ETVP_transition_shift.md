# ETVP: Механизм перехода — сдвиг, не выбор

## 1. Логика

Фиксация — не «выбор моды». Смена режима.
Как в голограмме: изменяешь угол — видишь другую проекцию.

## 2. Формализм

Ψ — голографическая запись.
Û(C_оп) — оператор считывания.
При изменении C_оп — меняется проекция.

## 3. Через ETVP

Ψ_проекция = Û(C_оп)·Ψ

C_оп > 0.8: суперпозиция.
C_оп < 0.8: фиксация.

## 4. Почему порог есть

Û — не непрерывный оператор.
Имеет дискретные режимы считывания.
Как голограмма имеет дискретные проекции.

## 5. Скептическая проверка

1. Почему Û дискретен? Не показано.
2. Почему порог 0.8? Не выведено.
3. Связь с Φ, π, √3 не показана.
