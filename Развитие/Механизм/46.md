# ETVP: Формализация воли, объём нейтронов, протокол эксперимента

## 1. Воля как оператор Ŵ

Û_эфф = Ŵ · Û

Ŵ = Σ_i w_i · |i⟩⟨i|

При высокой воле: один w_i → 1. Остальные → 0.

## 2. Связь воли с C_оп

|Ŵ| ∝ C_оп

Û_эфф = C_оп · Ŵ_hold · Û + (1 − C_оп) · Û

C_оп = 1: только удержание.
C_оп = 0: только стандарт (мысли).

## 3. Объём нейтронов

Объём — производная.
V_n = m_n / ρ_n

Удержание_n = ρ_n · V_n = m_n

Фиксация_n = m_n / шум

При шум > m_n: распад.
При шум < m_n: удержание.

## 4. Протокол эксперимента

Цель: проверить уравнение удержания на человеке.

Оборудование:
1. Датчик ∇C (Bi₂Te₃, ~$500)
2. ЭЭГ
3. Пульсометр
4. КГР

Схема:
1. Фон (5 мин)
2. Чувствование (10–15 мин)
3. Возврат (5 мин)
4. Повтор (3–5 циклов)

Измеряем:
| Величина | Прибор | Что показывает |
|---|---|---|
| ∇C | Bi₂Te₃ | Локальная когерентность |
| C_оп | ЭЭГ | Коррелят воли |
| Пульс | Пульсометр | Вегетатика |
| КГР | Датчик кожи | Стресс/покой |

Ожидаемый результат:
При чувствовании: ∇C растёт, ЭЭГ синхронизируется.
При возврате: ∇C падает, ЭЭГ десинхронизируется.

Критерий опровержения:
Если ∇C не меняется при чувствовании — модель опровергнута.

Стоимость: ~$500–1000. Срок: 1–2 месяца.
