# ETVP: Численная проверка механизма фиксации

## 1. Что нужно проверить

Гипотеза: при C < 0.8 V(Ψ,C) имеет несколько минимумов.

## 2. План

1. Взять E8.
2. Построить M(C) для разных C.
3. Найти λ_i(C).
4. Построить V(Ψ,C).
5. Проверить число минимумов.

## 3. Ожидаемый результат

C = 1: один минимум (суперпозиция).
C < 0.8: несколько минимумов (фиксация).

## 4. Если подтвердится — механизм найден.
   Если нет — гипотеза опровергнута.

## 5. Что нужно

Написать код для численного исследования V(Ψ,C).
