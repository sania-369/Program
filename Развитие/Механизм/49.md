# ETVP: Формализм воли Ŵ — завершение

## 1. Свойства Ŵ

1. Эрмитовость: Ŵ† = Ŵ
2. Диагональность: в базисе режимов
3. Норма: ||Ŵ|| = C_оп
4. След: Tr(Ŵ) = 1
5. Идемпотентность: Ŵ² ≠ Ŵ (общий случай)
6. Спектр: w_i действительны, неотрицательны

## 2. Коммутаторы

1. [Ŵ, Û] ≠ 0 — подтверждено численно
2. [Ŵ, Û_эфф] = Ŵ²Û − ŴÛŴ
3. [Ŵ, C_оп] = 0 — C_оп число
4. [Ŵ, ∇C] — гипотеза: не коммутируют

## 3. Связь с уравнением удержания

Удержание = C_оп · n
где n — число режимов в Ŵ.

При n = 1: один режим. Фиксация.
При n → ∞: много режимов. Суперпозиция.

Фиксация = C_оп · n / шум

## 4. Финальный формализм

Û_эфф = Ŵ(C_оп) · Û
Ŵ = Σ_i w_i |i⟩⟨i|, ||Ŵ|| = C_оп, Σ w_i = 1
[Ŵ, Û] ≠ 0
Удержание = C_оп · n
Фиксация = C_оп · n / шум
