# ETVP: Связь Û с динамикой C

## 1. Что происходит при измерении

При измерении C падает скачком:
ΔC_изм = −k · S_ext
где k — коэффициент связи (не выведен)

## 2. Что происходит с Û

1. C падает скачком
2. M·(1 + 0.1(C − C_FFS)) меняется
3. φ меняется
4. M_imag меняется
5. Собственные значения M меняются
6. Одна мода становится доминирующей

## 3. Гипотеза фиксации

Фиксация = смена доминирующей моды при изменении C.
Доминирующая мода — максимальная по |λ|.

## 4. Скептические замечания

1. Почему именно доминирующая мода? Не доказано.
2. Почему k не выведен?
3. Связь с порогом 0.8 не показана.
