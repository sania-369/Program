# ETVP: C_оп как фаза

## 1. Гипотеза

C_оп — фаза φ в комплексном пространстве.
Ψ = A·e^{iφ(C_оп)}

## 2. Режимы

φ = 0: действительная часть. Суперпозиция.
φ = π/2: мнимая часть. Фиксация.

## 3. Связь с кодом

φ = (π/2)(1 − (C − C_min)/(C_max − C_min))

При C = C_min: φ = π/2. Фиксация.
При C = C_max: φ = 0. Суперпозиция.

## 4. Скептическая проверка

1. Почему φ = 0 даёт суперпозицию? Не показано.
2. Почему φ = π/2 даёт фиксацию? Не показано.
3. Порог 0.8 не выведен из этой формулы.
