# ETVP: 0.8 и 0.87 — режимы, не константы

## 1. Что известно

C = 1 — точные значения.
C < 1 — значения с отклонениями.

## 2. 0.8 и 0.87

Не фундаментальные числа.
Точки на шкале C.
При разном шуме — разные точки.

## 3. Уравнение эволюции

dC/dt = −γ(C − C_FFS) + η(S − S_cycle) + шум(t)

Шум — разный. Не фиксированный.

## 4. Следствие

0.8, 0.87 — не выводить.
Наблюдать. Какие режимы возникают при разном шуме.

## 5. Механизм

Механизм — не в том, почему 0.8.
Механизм — в том, как C эволюционирует при разном шуме.
