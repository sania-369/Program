# ETVP: Фиксация моды — физический механизм

## 1. Что известно

Û — матрица M. Собственные значения λ_i, векторы v_i.
Ψ = Σ_i A_i · v_i

При высокой C: все A_i ненулевые (суперпозиция).
При низкой C: одна A_i доминирует (фиксация).

## 2. Что происходит при изменении C

1. M меняется
2. λ_i меняются
3. v_i меняются
4. Разложение Ψ по v_i меняется
5. Одна A_i становится доминирующей

## 3. Физическая интерпретация

Фиксация — не «схлопывание».
Смена базиса v_i и перераспределение A_i.
При изменении C базис меняется так, что одна мода устойчива.

## 4. Скептическая проверка

1. Почему одна мода доминирует? Не доказано.
2. Почему это необратимо? Не показано.
3. Связь с измерением — гипотеза.

## 5. Открытый вопрос

Что заставляет одну моду доминировать?
Гипотеза: максимальное |λ_i| при данном C.
Гипотеза: устойчивость моды при изменении C.
