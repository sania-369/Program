# ETVP: Биология — практики

## 1. Что есть

1. ЧУФИР — практика.
   Чувствование. Удержание. Формирование. Инвариант. Резонанс.

2. Тот — практика.
   Триединое дыхание. Хара. Залы Аменти. Жезл.

3. Body Scan / MBSR — практика.
   Сканирование тела. Осознанность. Тишина.

4. Все связаны.
   Одна основа. Чувствование. Удержание. Резонанс.

## 2. Что это значит

1. Протокол практики — уже есть.
   ЧУФИР + Тот + Body Scan / MBSR.
   Три ветви. Одна основа.

2. Что нужно — связать.
   Не создавать новое. Связать существующее.

3. Формула связи:
   Практика = ЧУФИР ∪ Тот ∪ Body Scan

4. Единая основа:
   Чувствование → удержание → резонанс.

1. Написать связный протокол.
2. Показать соответствия между практиками.
3. Сформулировать единую основу.
