# ETVP: Фиксация как смена масштаба (фрактальность)

## 1. Логика

Φ — самоподобие. Фрактал.
Фиксация — не «событие». Смена масштаба проявления.

## 2. Формализм

Фиксация = смена масштаба ∝ Φⁿ
n — уровень фрактала.

C_оп > 0.8: масштаб n. Суперпозиция.
C_оп < 0.8: масштаб n+1. Фиксация.

## 3. Почему порог 0.8

При C ≈ 0.8 система переходит на следующий уровень фрактала.
Масштаб меняется. Проекция меняется.

## 4. Скептическая проверка

1. Почему переход при C ≈ 0.8? Не выведено.
2. Как связан уровень фрактала с C? Не показано.
