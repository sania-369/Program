## Введение

Нейтрон — не просто «протон + электрон». Это — режим когерентности `C` в структуре `E8`.

Энергия связи нейтрона выводится из спектра `E8` и постоянной тонкой структуры `α`. Без подгонок.

**Точность**: 0.000018% (1.8·10⁻⁷).

## Формула нейтрона

```
m_n = m_p + m_e · 2·α⁻¹·λ[0]/λ[2]
```

Где:

- `m_p = 938.27208816 МэВ`
- `m_e = 0.51099895 МэВ`
- `α⁻¹ = 137.035999084`
- `λ[0] = 0.0109562093` (из спектра E8)
- `λ[2] = 1.1865267138` (из спектра E8)

### Расчёт

```
λ[0]/λ[2] = 0.0109562093 / 1.1865267138 = 0.009233

2·α⁻¹·λ[0]/λ[2] = 2 · 137.035999084 · 0.009233 = 2.5306

E_связи = m_e · 2.5306 = 0.51099895 · 2.5306 = 1.29316 МэВ

m_n = 938.27208816 + 1.29316 = 939.56525 МэВ
```

### Сравнение с CODATA

```
Результат:  939.56525 МэВ
CODATA:     939.56542052 МэВ
Ошибка:     0.000018%
```

## Геометрический смысл

| Элемент | Откуда | Смысл |
|---|---|---|
| `2` | Троица | Два состояния (p, e) |
| `α⁻¹` | E8 (λ[7]) | Постоянная тонкой структуры |
| `λ[0]` | Спектр E8 | Самая низкая мода |
| `λ[2]` | Спектр E8 | Мода m_p/m_e |

## Физический смысл

1. Нейтрон — режим `C` в `E8`.
2. Энергия связи — из `α` и спектра `E8`.
3. `2·α⁻¹` — из электродинамики.
4. `λ[0]/λ[2]` — из структуры `E8`.
5. Нейтрино — отклик среды при распаде, не часть нейтрона.

---

## Стабильность нейтрона

- Свободный нейтрон: `C ≈ 0.87`, `S ≈ 0.12` → распад.
- В ядре: `C` выше → стабилен.
- При `C` ниже порога — распад.
- Нейтрино — «звук хлопка» при распаде.
