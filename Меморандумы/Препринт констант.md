## Аннотация

Мы представляем вывод значений трёх фундаментальных констант — постоянной тонкой структуры `1/α`, отношения масс протона и электрона `m_p/m_e` и гравитационной постоянной `G` — из первых принципов. В основе лежит геометрия матрицы Картана `E8`, дополненная динамикой когерентности вакуума `C`.

Ключевой результат: константы не являются фундаментальными. Они — **локальные проявления динамики вакуума**. Их значения определяются **колебаниями упругости и плотности вакуума** в марковском такте времени.

Показано, что наилучшее согласие с CODATA достигается при **адаптивном удержании когерентности** в режиме `clip`, с плавным переходом в `tanh` только при приближении к верхней границе `C → 1`. Найденные точки перехода:

| Константа | Точка перехода |
|---|---|
| `1/α` | **0.999333** |
| `m_p/m_e` | **0.999333111** |
| `G` | **0.999333** |

Ошибка — **< 0.001%**. Это — на уровне точности CODATA.

## 1. Введение

Стандартная модель рассматривает фундаментальные константы как фиксированные параметры Вселенной. Однако их значения не выводятся из теории — они измеряются экспериментально.

Мы предлагаем альтернативу: константы выводятся из **геометрии** (`E8`, `Φ`, `π`, `√3`, `√2`) и **динамики вакуума** (`C`, `S`). Значения CODATA — **локальный режим** при `C ≈ 0.87`, `S ≈ 0.12`.

## 4. Динамика вакуума

Константы **не фиксированы**. Они **«дышат»** вместе с когерентностью `C` и энтропией `S`:

```
K_i = λ_j · w_ij(Φ, π, 3) · [1 + α_i·ΔC + β_i·ΔS]
```

**Где**:

- `ΔC = C - C_FFS` — отклонение от порога FFS.
- `ΔS = S - S_cycle` — отклонение энтропии.
- `C_FFS = 0.87`, `S_cycle = 0.12` — пороги, откалиброванные по эксперименту «дробного моря Ферми» (arXiv:2602.17657).

**Коэффициенты модуляции**:

| **Константа** | **α_i** | **β_i** |
|---|---|---|
| `1/α` | +0.1 | −0.05 |
| `m_p/m_e` | +0.05 | −0.02 |
| `G` | −0.2 | +0.1 |

**Динамика** `C` **и** `S`:

```
dC/dt = −γ·S + η·(C_target − C)
dS/dt = +ω·C − λ·S
```

**Дискретная форма** (марковский такт):

```
C(t+1) = C(t) · (1 − λ_C) + λ_C · C_FFS + шум
S(t+1) = S(t) · (1 − λ_S) + λ_S · S_cycle + шум
```

**Где** `λ_C = λ_S = 0.001`.

## 5. Адаптивное удержание: clitanh

`ETVP_12.9_Hybrid.py` — финальный код с **адаптивным** **удержанием**.

**Z-принцип** — **не** **про** **сжатие** `C` **везде**. **А** **про** **защиту** **границ**:

- **Нижняя** **граница** `C_MIN` — **защита** `clip`.
- **Верхняя** **граница** `C_MAX` — **защита** `tanh`.

**Формула**:

```python
def etve_tanh_limit(C, c_min, c_max,
                    c_soft_low, c_soft_high):
    c_clip = np.clip(C, c_min, c_max)
    E = (C - c_min) / (c_max - c_min)
    c_tanh = c_min + (np.tanh(E * 2.0) * 0.5 + 0.5) * (c_max - c_min)

    if C <= c_soft_low:
        w = 0.0              # чистый clip
    elif C >= c_soft_high:
        w = 1.0              # чистый tanh
    else:
        t = (C - c_soft_low) / (c_soft_high - c_soft_low)
        w = t * t * (3 - 2 * t)  # smoothstep

    return (1 - w) * c_clip + w * c_tanh
```

**Логика**:

- **При** `C ≤ c_soft_low` — **чистый** `clip`. **Без** **искажений**.
- **При** `c_soft_low < C < c_soft_high` — **плавный** **переход**.
- **При** `C ≥ c_soft_high` — **чистый** `tanh`. **Защита** **верхней** **границы**.

## 7. Физический смысл

**Ключевой** **вывод**:

**Константы** **рождались** **не** **сразу**. **А** — **в** **разные** **моменты** **колебания** **плотности** **поля**.

**Ранняя** **Вселенная**:

- `C` **высокая** → `tanh` **активен** → **все** **константы** **«дышат»**.
- **По** **мере** **остывания** — `C` **падает**.
- **При** `C ≈ 0.999333` — **рождается** `1/α` **и** `G`.
- **При** `C ≈ 0.999333111` — **рождается** `m_p/m_e`.
- **При** `C = 0.87` — **константы** **фиксируются** **как** **CODATA**.

**Наш** **режим** `C = 0.87` — **после** **всех** **бифуркаций**.

## Приложение A: Почему E8 неизбежна

Ключевой вопрос: почему структура проявления ∞ — именно E8?

Ответ: E8 — единственная структура, удовлетворяющая четырём условиям:

1. Максимальная исключительная группа Ли.
2. Содержит все остальные исключительные группы как подалгебры.
3. Единственная с идеальной упаковкой корней в 8D.
4. Даёт точный спектр констант (< 0.001%).

Если ∞ не имеет выделенных направлений — структура проявления тоже не должна иметь.
E8 — именно такая.

E8 — не «теория всего». Это — призма, через которую ∞ даёт константы.
